# コーバック号 / CORBACK II

[指定の参考ページ](http://noboland.web.fc2.com/corback.htm)に掲載されている青い「コーバックⅡ世」の側面・上面・前後写真を参考に、Blenderで制作したゲーム用モデルです。写真から見えない細部は簡略化しています。

尖ったロケット型の船体、前寄りの艦橋と白い「1」、潜望鏡、X字の尾翼、先端の4基の後方発射ポッド、背面のブリスター、側面の排水孔と星の標識、艦尾のタービンを表現しました。ポッドは外観の再現で、ゲームの武器仕様は従来の2機目を引き継ぎます。

- `corback.blend`: 編集用99パーツとゲーム出力用シーン、プレビュー用スタジオ。コーバックのデータだけを保存しています。
- `build_corback.py`: 現在のシーンを残し、新しいシーンに機体を作ります。
- `export_corback.py`: 続けて実行するとGLBと編集用ファイルを保存し、プレビューのカメラを用意します。`ROOT`を自分のチェックアウトに合わせてください。
- `../../public/models/corback.glb`: 13,836三角形、2ノード、7描画、約317KiB。テクスチャの外部読み込みはありません。
- `../../public/images/corback-preview.png`: 機体選択用の透過プレビュー。出力スクリプトの後に`bpy.ops.render.render(write_still=True)`で再生成できます。

Blenderの船首は+Y、上は+Z。glTFでは船首-Z、上+Yとなり、全長約12.2ゲーム単位です。`Corback_Rotor_Game`は艦尾の独立ノードで、ゲーム中にZ軸回転します。

放棄機体を発見して任務をクリアするとアンロックされます。セーブのバージョン2では、旧`manta-x1`の取得状態と選択状態を`corback`へ移し、スコアも保持します。未取得のセーブが自動でアンロックされることはありません。
