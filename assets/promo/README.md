# 『深海のゼロ』30秒プロモーション動画

出力：`../../output/shinkai-zero-promo-30s.mp4`。1920×1080、24fps、720フレーム、30秒。H.264映像とAACステレオ音声。

ゲーム内のGLBをBlenderでレンダリングし、パン・ズーム、日本語テロップ、対象が切り替わるレーダー図解、オリジナルの音楽と効果音を合わせた演出映像です。ゲームプレイの録画ではありません。

| 時間 | カット |
| --- | --- |
| 0–4秒 | りゅうおうとタイトル |
| 4–8秒 | アクティブソナー |
| 8–12秒 | たいげい型の敵と緑色ロック対象の切替 |
| 12–16秒 | 魚雷戦 |
| 16–20秒 | コーバック号の発見・解放 |
| 20–25秒 | 円盤型ボス |
| 25–30秒 | エンドタイトル |

## 再生成

1. Blenderで`render_stills.py`を実行。ゲーム用のGLBを読み込み、使用する7カットを`stills/`へ保存します。既にある画像は再利用します。
2. NumPyとPillowが使えるPythonで`make_graphics_audio.py`を実行。テロップ、レーダー図解、30秒の音源、`storyboard.json`を生成します。日本語フォントにはmacOSのヒラギノ角ゴシックを使用します。
3. Blenderで`edit_promo.py`を実行。`qa/`へ7カットの確認画像を出し、編集可能な`promo-30s.blend`と最終MP4を保存します。

音源はスクリプトで合成した低音、和音、パルス、打音、ソナー音、衝撃音です。外部の楽曲・音源は使用していません。機体モデルの参照元は各機体のREADMEを参照してください。
