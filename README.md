# 深海のゼロ

暗い氷海で敵を探知し、魚雷で撃破する三人称視点の潜水艦アクションゲームです。

初期の自機は『青の6号』の「りゅうおう」です。[指定の参考記事](http://blog.livedoor.jp/yoshikawa_amm/archives/2189583.html)をもとにBlenderで制作し、青い発光スリットと二重反転スクリューを備えたGLBとして読み込みます。編集データと再生成手順は[assets/ryuou](assets/ryuou/README.md)にあります。既存セーブのスコアとアンロックは引き継ぎます。

アンロック機体は「コーバック号」です。[参考ページ](http://noboland.web.fc2.com/corback.htm)の青いⅡ世をBlenderで制作し、尖った船首とX字尾翼を再現しました。編集データは[assets/corback](assets/corback/README.md)にあります。旧MANTA X-1を取得済みならコーバック号へ引き継ぎます。

## 起動

Node.js 20.19以降を推奨します。

    npm install
    npm run dev

ブラウザで http://localhost:3000 を開きます。

本番ビルド：

    npm run build
    npm start

## 描画負荷と検証

高密度ディスプレイでも3D描画のピクセル比を最大1に抑えます。HUDの文字は
ブラウザ本来の解像度で表示されます。氷塊54個はインスタンス描画でまとめ、
小さな灯火は発光色で表現し、爆発の周辺照明には固定の2灯を使います。
HUD更新では3Dシーンを再構築せず、ポーズ中は連続描画を停止します。

描画処理の軽量化時に、旧自機で変更前後を同じローカル開発環境・1280×720のブラウザで開始位置から計測したところ、
10秒ごとの平均FPSは約23〜30から約38〜42、平均描画呼び出しは約94〜104回から
約42〜50回に変化しました。端末・ブラウザ・戦闘状況によって値は変わります。

検証コマンド：

    npm test
    npm run lint
    npm run typecheck
    npm run build

衝突判定テストでは面・辺・角・内部への接触と、10,000個の固定シードの位置からの
押し戻しを確認します。りゅうおうのGLBの内容・向き・サイズ・描画量と、旧セーブからのスコア・アンロックの引き継ぎもテストします。

## ゲームの流れ

1. アクティブソナーで敵を探知します。ソナーを使うと敵もプレイヤーを発見します。
2. Eで探知済みの敵をロックし、誘導魚雷を発射します。
3. Tabで手動魚雷へ切り替えると、ロックなしで高威力の魚雷を撃てます。
4. 観測施設付近の記録点を通過すると、撃沈後にそこから再開できます。
5. 深部にいる円盤型巨大潜水艦を撃破するとステージクリアです。
6. 観測施設付近の放棄機体を発見してからクリアするとコーバック号がアンロックされます。

護衛艇は開始時に2隻だけ配置され、その後は時間をおいて1隻ずつ増援されます。
通常敵が同時に出現する数は最大3隻です。

戦闘海域は横幅480m、奥行き1,240m、水深279mまで航行できます。
氷塊の間隔も広げてあり、横への回避や深い位置からの接近ができます。
アクティブソナーは発信位置から650mまで広がり、波が通過した表面を約2.4秒間照らします。
氷塊・海底・氷床・構造物は青緑、敵潜水艦（ボスを含む）はオレンジに光ります。
表面の発光は既存の描画に組み込み、追加のライトや重複したモデルを使いません。

氷塊、構造物、氷床、海底へ高速で衝突すると船体へ少量のダメージを受け、
速度が落ちて反対方向へ押し戻されます。魚雷は推進時間を過ぎると誘導と推進力を失い、
海底へ沈んで着底時に爆発します。
航走中の魚雷も、氷塊や構造物、別の魚雷、機雷、デコイへ接触すると爆発して消滅します。
